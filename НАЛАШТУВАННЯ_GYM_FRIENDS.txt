GYM TRACKER 3.0 — ПЕРШЕ НАЛАШТУВАННЯ ЗАКРИТОЇ ГРУПИ

ВАЖЛИВО: правила Firestore зараз НЕ оновлено автоматично. Не надсилайте друзям посилання до налаштування і тестування правил.

1. Спочатку збережіть JSON-копію тренувань у розділі «Дані» на обох пристроях.
2. У Firebase Console → Authentication → Users відкрийте свій запис та скопіюйте User UID (НЕ email, НЕ API key).
3. У GitHub у вже наявному файлі firebase-config.js після об'єкта конфігурації додайте окремий рядок:
   window.GYM_FRIENDS_OWNER_UID = 'ТУТ_ВАШ_FIREBASE_UID';
   Не видаляйте існуючий window.GYM_FIREBASE_CONFIG.
4. Відкрийте файл firestore-gym-friends.rules.txt із архіву. Замініть REPLACE_WITH_OWNER_UID на той самий UID.
5. У Firebase Console → Firestore Database → Rules замініть правила на вміст цього файлу й натисніть Publish. Нові правила залишать право на /users/{uid}/backups тільки для власника. Перевірте, що UID однаковий у правилах і конфігурації.
6. У GitHub завантажте з архіву тільки застосункові файли: index.html, sw.js, manifest.webmanifest, іконки, README.txt, .nojekyll. НЕ завантажуйте файл правил .txt як застосунковий файл, не перезаписуйте firebase-config.js.
7. Перевірте на ПК і телефоні, що відображається v3.0.0, власна синхронізація продовжує працювати, а у вкладці «Друзі» видно ваш UID.
8. Друг зможе встановити той самий застосунок, увійти через Google у вкладці «Друзі», скопіювати свій UID і надіслати вам. Ви введете UID друга у своїй вкладці «Друзі» та додасте його.
9. Друг натискає «Оновити групу», обирає нікнейм і натискає «Опублікувати мої рекорди». Це ОКРЕМА ручна публікація лише статистики, не повних тренувань.
10. Для виключення друга натисніть «Виключити». Його опублікована статистика також видаляється. Його особисті локальні дані залишаються на його пристрої.

НЕ передавайте друзям свій Google-акаунт, логін або пароль. UID не є секретним ключем, але використовуйте його лише для ідентифікації запрошення.

УВАГА: Це початкова тестова версія. Відпрацювання прав доступу у Firebase Console / Rules Playground і тест двома окремими акаунтами обов'язкові перед розсилкою. Застосунок не дозволяє друзям автоматично синхронізувати повні тренування, коли прописаний OWNER UID. Для них повні тренування залишаються тільки локально.

Усі результати вводяться користувачами, тому рейтинг не є перевіреним незалежно.
